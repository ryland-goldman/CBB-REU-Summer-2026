# Cornell Linac beam simulation -- Python dependencies
#
# PREFERRED: install everything from conda-forge (this is how the reference CBB env was
# built). Note the conda package names that differ from the pip names:
#   pip `pywarpx`  -> conda `warpx`    (bundles the pywarpx module + the lume `warpx` wrapper)
#   ImpactTexe     -> conda `impact-t` (the serial Impact-T binary linac5-8 runs via lume-impact)
# One-shot env creation:
#   conda create -n CBB -c conda-forge 'warpx=26.03' impact-t openpmd-api openpmd-viewer \
#       lume-impact openpmd-beamphysics easygdf numpy scipy matplotlib tqdm pandas
# PIN warpx=26.03: warpx 26.04 regressed RZ + openPMD diagnostics — every RZ stage
# (gun/injector/linac1-4) aborts at init with "Dynamic cast returned a nullptr!". 26.03 is the
# last release with the magnetostatic picmi kwargs lume-warpx needs AND a working RZ openPMD path.
#
# EXTERNAL (not a pip/conda dep): the converter stage shells out to the `g4bl` binary from
# G4beamline 3.08 (https://g4beamline.muonsinc.com), which must be installed and on PATH.
#
# FALLBACK: `pip install -r requirements.txt` into an env that already has
# warpx / impact-t / openpmd-api from conda (those need C++/Fortran cores).

# Core PIC engine + LUME wrapper (cathode/gun/injector/linac1-4 drive WarpX via a YAML config).
